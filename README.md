# Nestor Collective — Website

Prototipo (demo 1): hero, belief, globo interactivo y equipo. Vanilla HTML/CSS/JS, un solo archivo.

- `index.html` — el sitio. Ciudades del globo en `CITIES`, equipo en `TEAM`.
- `img/equipo/` — fotos del equipo (webp, 1000px alto).
- `build_artifact.py` — genera la version con fotos embebidas para publicar como Artifact.

Deploy: Vercel apuntando a la raiz del repo (sitio estatico, sin build).
